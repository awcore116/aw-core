# aw-core — Artificial Wisdom Framework (Open Core)

**AI gives you reasoning. AW gives you judgment.**

This repo contains the open methodology, routing logic, and reference implementations behind AW — a framework for structured, rule-based decision-support models. It is not a chatbot and does not use an LLM to make judgments; every recommendation is produced by deterministic, auditable logic you can read line by line.

---

## What this repo is

- The **routing specification** — how an input decision gets tagged and matched to the right judgment model(s)
- **Reference implementations** of a subset of AW's judgment models, fully open — read the classifier, the scoring formula, the thresholds, the output logic
- A **methodology**, not a black box — every score, weight, and threshold is visible and editable

## What this repo is NOT

- Not the full model set. AW's production system runs a larger library of judgment models beyond what's included here.
- Not the hosted service. The reference code here is for inspection, learning, and self-hosting a limited version — the full, tuned, maintained system is available as a hosted API (see [Hosted AW](#hosted-aw) below).
- Not an LLM wrapper. There's no prompt engineering here to inspect — the logic is plain conditionals and weighted scoring, which is the point.

---

## Why open the methodology at all

Judgment tools carry a trust problem that most software doesn't: if a system is telling you (or your users) what the "wise" move is, "trust me" isn't good enough. This repo exists so anyone — developers, researchers, skeptics — can verify:

- What signals a decision gets tagged with
- How those signals turn into a score
- Why one judgment model gets invoked over another
- What logic actually produces the output text

Nothing here is generated by an LLM guessing at what sounds wise. It's rules, and you can read all of them.

## Repository structure

```
/routing/
  signals.js                 — shared signal extraction (keyword/pattern matching)
/models/
  ledger/index.js             — utilitarian reference model (full implementation)
  flow/index.js                — non-forcing/timing reference model (full implementation)
/examples/
  run-examples.js             — runnable worked examples for both models
LICENSE.md                     — MIT license + scope note
CONTRIBUTING.md                 — how to contribute, what will/won't be merged
ARCHITECTURE.md                 — how the pieces fit together, how this relates to full AW
package.json
```

Run the examples yourself:
```
npm install
npm run example
```

This repo ships two reference implementations: **Ledger** (utilitarian — confidence-weighted cost/benefit across stakeholders) and **Flow** (non-forcing/timing — is this the right moment to act, or is acting now forcing against resistance). Both are chosen because their logic is fully verifiable math/threshold logic, with no ambiguous qualitative judgment calls hidden inside.

---

## Scope

AW's full judgment library is larger than what's included here. This repo ships:

- The complete routing/orchestration logic (this is fully open — how inputs get classified and matched)
- A small number of reference judgment models, chosen because they're the easiest to independently verify (transparent scoring math, no ambiguous qualitative judgment calls)

The remaining judgment models — along with tuned production weights, expanded signal lexicons, and hosted infrastructure — are part of the commercial AW API.

## FAQ

**Is this an LLM?**
No. AW's judgment logic is deterministic — no model call happens during scoring or routing. It can be paired with LLMs (e.g., to generate natural-language phrasing of an output), but the judgment itself is rule-based.

**Why keep some models closed?**
The open reference models demonstrate the methodology is real and auditable. The full library represents ongoing R&D and is what funds continued maintenance of both the open and commercial parts of AW.

**Can I use this commercially?**
